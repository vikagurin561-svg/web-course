Переглянути лабораторні

Лабораторні роботи

Git і GitHub Pages

Створення репозиторію та публікація першої сторінки на GitHub Pages.

Клієнт-серверна взаємодія

Дослідження URL, DNS, HTTP-запитів, кешування й TLS засобами інструментів розробника.

Структура HTML-документа

Розмітка заголовків, списків, цитат і коду; перевірка в W3C Validator.

Семантична реорганізація

Перетворення «дів-супу» на семантичну сторінку з доступністю та структурованими даними.

Технології

  • HTML5: мова розмітки та структурування вмісту
  • CSS3: оформлення та адаптивна верстка
  • Git і GitHub: контроль версій і публікація сайту
  • Інструменти розробника: аналіз мережі та налагодження

Примітка
